# 1 Control-plane và 2 Worker

## Trường hợp dùng Tailscale

### Khởi tạo trên Master

```bash
sudo kubeadm init \
 --control-plane-endpoint="<IP_TAILSCALE_MÁY_1>:6443" \
 --upload-certs

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
```

### Tham gia cụm từ Worker

```bash
sudo kubeadm join <IP_TAILSCALE_MÁY_1>:6443 --token <TOKEN> \
 --discovery-token-ca-cert-hash sha256:<hash>
```

## Trường hợp Không dùng Tailscale (Mạng LAN)

### Khởi tạo trên Master

```bash
sudo kubeadm init

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
```

### Tham gia cụm từ Worker

```bash
sudo kubeadm join 192.168.100.201:6443 --token x \
 --discovery-token-ca-cert-hash sha256:x
```

## Cài đặt Mạng (Network Plugin - Calico)

```bash
kubectl apply -f https://raw.githubusercontent.com/projectcalico/calico/v3.25.0/manifests/calico.yaml
```

## Một số lệnh quản lý Node

### Bỏ Taint để Master có thể chạy Pod như Worker

```bash
kubectl taint nodes <node_name> node-role.kubernetes.io/control-plane:NoSchedule-
```

### Chuyển đổi vai trò (Role) cho Node

```bash
# Xóa role control-plane
kubectl label node <node_name> node-role.kubernetes.io/control-plane-

# Thêm role master
kubectl label node <node_name> node-role.kubernetes.io/master=
```

## Cài đặt Mạng (Network Plugin - Calico)


# Gỡ bỏ cụm (Reset Kubernetes)

Thực hiện các lệnh sau để xóa cấu hình Kubernetes trên Node và trở về trạng thái ban đầu:

```bash
sudo kubeadm reset -f
sudo rm -rf /var/lib/etcd
sudo rm -rf /etc/kubernetes/manifests/*
```
